# حزمة تثبيت Laravel لمقرر تقانات الإنترنت

إعداد الطالب: **سراج شبلي** · السنة الثانية، هندسة البرمجيات

## ⬇️ التنزيل

**[اضغط هنا لتنزيل LaravelKit.exe](https://github.com/sirajshipli8155-netizen/laravel-kit/releases/latest/download/LaravelKit.exe)** (الحجم 617 MB)

- نزّل الملف على **الحاسوب المحمول (Windows)** مباشرة، فهو برنامج يعمل على Windows فقط.
- إذا انقطع الإنترنت أثناء التنزيل، فأكمِله من قائمة التنزيلات في المتصفح، ولا داعي للبدء من جديد.
- يمكن تنزيله من الهاتف أيضاً، لكن يجب بعد ذلك نقله إلى الحاسوب بكابل USB أو بذاكرة فلاش.

## طريقة التثبيت

1. انقر على **LaravelKit.exe** نقراً مزدوجاً، واختر مكان الاستخراج (مثلاً `C:\`)، ثم اضغط **Extract**.
2. افتح المجلد الناتج وشغّل **Laravel-Setup.bat**.
   - إذا ظهرت شاشة "Windows protected your PC" فاضغط **More info** ثم **Run anyway**.
3. في النافذة التي تظهر اضغط **ثبّت / أكمِل التثبيت**.
   - إذا كان على جهازك XAMPP أو PHP قديم معطّل فاضغط **تنظيف وتثبيت نظيف**.
4. بعد الانتهاء افتح المجلد **«تقانات الإنترنت»** على سطح المكتب، وابدأ بالعنصر **0- ابدأ من هنا**.

أغلق VS Code و XAMPP قبل التثبيت، ولا تستخدم VPN. ولا يحتاج التثبيت إلى الإنترنت.

## ماذا تثبّت الحزمة؟

PHP 8.5، و Composer، و Laravel، و Git، و Node.js، و VS Code، و XAMPP (Apache و MySQL و phpMyAdmin)، و Postman، ومشروع المادة (Laravel 12 مع React)، ومجلد «تقانات الإنترنت» مع دليل لكل برنامج.
